 # Rock Paper Scissors

 A simple browser-based Rock Paper Scissors game built with **HTML** and **JavaScript**.

 ## Preview

 Play the live project on GitHub Pages:

 [Open the live preview](https://majdabuhakmeh.github.io/rock-paper-scissors/)

 ## Features

 - Play Rock, Paper, Scissors against the computer
 - Instant result updates after each round
 - Simple, responsive interface
 - Runs directly in the browser with no dependencies

 ## Built With

 - HTML5
 - JavaScript

 ## Getting Started

 1. Clone or download this repository.
 2. Open the project folder.
 3. Open `index.html` in a web browser.

 No build tools or installation are required.

 ## How to Play

 1. Choose **Rock**, **Paper**, or **Scissors**.
 2. The computer selects a move automatically.
 3. Compare the choices to see the result.
